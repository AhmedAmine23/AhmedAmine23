### 🚀 Featured Engineering Projects

* 🚗 **[TRAXX Car Sensor Hub Migration](#)**
  * *What it is:* Re-architected a vehicle's ultrasonic sensor hub from Arduino to an **STM32** MCU.
  * *The Tech:* Implemented **FreeRTOS** worker-threads and an **SPI + DMA** data path to stream non-blocking telemetry to an **NVIDIA Jetson Nano** edge-compute layer.
  
* 🌍 **[IoT Environmental Supervision System](#)**
  * *What it is:* A full-stack real-time monitoring system for temperature and conductivity.
  * *The Tech:* **ESP32** sensor nodes streaming to **MySQL**, monitored via a responsive web dashboard and a local **Raspberry Pi GUI** built with **Qt Creator**.

* ⚡ **[11-Stage Ring Oscillator & CMOS Op-Amp](#)**
  * *What it is:* Custom analog IC designs focusing on stability and power efficiency.
  * *The Tech:* Designed, sized, and simulated in **Cadence Virtuoso** to meet strict VLSI target specs (frequency, phase margin, bandwidth).
